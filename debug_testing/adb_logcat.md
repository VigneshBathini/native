## ADB Basics

### What is ADB?

ADB (Android Debug Bridge) is a command-line tool that allows communication between a computer and an Android device.

### Common Commands

```bash
adb version
```

Checks installed ADB version.

---

```bash
adb devices
```

Lists connected Android devices.

---

```bash
adb shell
```

---

```bash
adb shell pm list packages
```

Lists all installed packages.

---

```bash
adb shell dumpsys package <package_name>
```

Displays package information.

---

```bash
adb logcat
```

Starts live log streaming.

---

```bash
adb logcat -c
```

Clears existing logs.

---

```bash
adb bugreport
```

Generates a complete device bug report.

# 5. Log Levels

This section needs corrections.

---

## Verbose

```java
Log.v(TAG, "Verbose message");
```

Shows **every log**.

Usually used during development.

---

## Debug

```java
Log.d(TAG, "Debug message");
```

Used for debugging application flow.

Example:

* Button clicked
* API called
* Navigation happened

---

## Info

```java
Log.i(TAG, "User logged in");
```

General application information.

Example:

* User Login
* Payment Success

---

## Warning

```java
Log.w(TAG, "Slow network");
```

Something unexpected happened, but the app can continue.

Example:

* Slow API
* Deprecated API
* Missing optional data

---

## Error

```java
Log.e(TAG, "API failed");
```

Serious issue.

Examples:

* API failure
* Exception
* Database error
* NullPointerException
* Network timeout

**Important correction:**

A crash is **not** automatically a `Log.e()`.

Many crashes appear as:

```
FATAL EXCEPTION
```

generated by Android itself.

ANRs also are not `Log.e()`.

---

## Assert

Android provides:

```java
Log.wtf(TAG, "Unexpected state");
```

There is **no** `Log.assert()` API.

So replace:

```java
Log.assert()
```

with

```java
Log.wtf()
```

---

## WTF

```java
Log.wtf(TAG, "Impossible state");
```

Meaning:

> "Something happened that should never happen."

Very rarely used.

## React Native Note

During React Native development, developers generally use:

```javascript
console.log()
console.warn()
console.error()
```

instead of

```java
Log.d()
Log.e()
```

`Log.d()` and related methods are mainly used in native Android (Java/Kotlin) code.

For a Play Store release build, JavaScript console logs may not be available, so Logcat may primarily display Android system logs, native logs (if implemented), crashes, ANRs, and runtime events.

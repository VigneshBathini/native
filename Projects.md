You mean how to verbally introduce each project when an interviewer asks, "Can you tell me about your projects?"

Here are natural, simple explanations you can speak:

### 1. AFMC Mess Application

"I worked on a Mess Management Application for AFMC. It helps manage daily mess operations, including food orders, inventory, stock management, and different user roles. I worked on both frontend and backend development using React Native, Node.js, Express.js, and MySQL. I was also involved in server deployment."

### 2. Transaction Optics Ledger Application

"I worked on a mobile application for an optical business to manage its customer transactions and ledger records. It was developed using React Native Expo, integrated with Oracle APEX REST APIs for backend operations, and included PDF report generation."

### 3. Proctor App

"I worked on an internal web application called Proctor, developed using React.js. My work was mainly focused on frontend development and building the required user interfaces."

### 4. Founder Community

"I worked on a Founder Community application designed to connect startup founders and provide a platform for networking and collaboration."

### 5. GSTS Application

"I worked on the GSTS company website using React.js, mainly focusing on frontend development and implementing user interfaces."

1. What the application does.
2. Which technologies you used.
3. What your contribution was.
